## Technical Summary
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript (Strict)
- **Styling**: Tailwind CSS (Luxury Dark Palette: Noir, Obsidian, Bronze, Gold)
- **Animation**: Framer Motion + GSAP (Parallax/Scroll) + Lenis (Smooth Scroll)
- **Icons**: Lucide Icons
- **Data Layer**: Decoupled CMS Adapter (Mock -> Headless Ready)
- **SEO**: Dynamic JSON-LD Schema (HairSalon, Service, LocalBusiness)
- **Current Phase**: Architecture & System Initialization (Phase 1)
